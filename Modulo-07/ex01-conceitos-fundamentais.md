# Exercício 1 — Conceitos fundamentais (obrigatório) 

    Responda com suas palavras (2 a 4 linhas cada):

## a. Qual é a função do AppServer?

R: O AppServer é o servidor de aplicação do Protheus, responsável por processar o código e fazer a comunicação com o banco de dados. No nosso caso, utilizamos um servidor local apenas para desenvolvimento durante a Jornada DEV da TOTVS.

## b. O que é o RPO?

R: É o Repositório de Objetos, é um arquivo que armazena todos os programas, códigos, rotinas e dicionários de dados, padrões ou customizados. É através dele que o AppServer executa as rotinas do Protheus. 

## c. Para que serve o Configurador (SIGACFG)?

R: o Modulo Configurador é onde nos conseguimos gerenciar usuários e senhas, manipular o dicionário de dados e definir parâmetros. Também permite tornar campos obrigatórios, renomear títulos, criar
campos customizados e adicionar novas abas em tabelas padrão.

## d. Qual a diferença entre campo Real e campo Virtual no SX3?

R:  o campo real ocupa espaço físico no banco de dados e grava a informação permanentemente na tabela.Enquanto o campo virtual não ocupa espaço fisico no banco, sendo utilizado apenas para exibir ou calcular informações na interface do sistema, sem gravá-las na tabela.
