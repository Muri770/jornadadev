## A) Calcular área de um retângulo

```text
INÍCIO

Ler base
Ler altura

Calcular área:
Área = Base * Altura

Mostrar área do retângulo

FIM
```

## B) Verificar se um número é par ou ímpar

```text
INÍCIO

Ler número

Verificar se o número é divisível por 2

SE for divisível por 2 ENTÃO
    Mostrar "Número Par"

SENÃO
    Mostrar "Número Ímpar"

FIM
```

## C) Encontrar o maior entre três números

```text
INÍCIO

Ler número A

Ler número B

Ler número C

Considerar A como o maior número

SE B for maior que o maior número ENTÃO
    O maior número passa a ser B

SE C for maior que o maior número ENTÃO
    O maior número passa a ser C

Mostrar o maior número

FIM
```
