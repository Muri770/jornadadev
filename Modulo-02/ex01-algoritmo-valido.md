# Exercício 1 - Isto é um algoritmo válido?

## A) "Some dois números."

**Resposta:** Não é um algoritmo válido.

**Justificativa:**
A instrução está incompleta, pois não informa quais números devem ser somados nem o que deve ser feito com o resultado.

---

## B) "Leia um número. Se for positivo, mostre 'positivo'. Senão, mostre 'negativo'."

**Resposta:** É um algoritmo válido.

**Justificativa:**
Possui uma sequência lógica de passos, apresenta uma decisão e possui um resultado definido.

---

## C) "Fique repetindo até acabar."

**Resposta:** Não é um algoritmo válido.

**Justificativa:**
A instrução não informa qual é a condição para terminar a repetição, podendo gerar uma repetição infinita.

---

## D) "Pegue um ingrediente qualquer e cozinhe."

**Resposta:** Não é um algoritmo válido.

**Justificativa:**
A instrução é muito vaga, pois não informa qual ingrediente utilizar nem quais passos devem ser seguidos para cozinhar.
